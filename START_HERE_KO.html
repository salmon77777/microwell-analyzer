# WellScope LAMP v1.1.0 업데이트

## 가장 먼저 할 일
기존 GitHub 저장소를 지우지 마세요. 압축 안의 내용물을 기존 app.py가 있던 위치에 올려 같은 이름의 파일을 교체합니다. `.devcontainer`는 그대로 둬도 됩니다. 시작 파일 경로는 `app.py`입니다.

이번 버전은 app.py만 바꾸면 안 됩니다. 아래 6개 Python 파일, requirements.txt, .streamlit/config.toml을 함께 적용하세요.

- app.py / wellscope_core.py / wellscope_report.py
- wellscope_batch.py / wellscope_standards_ui.py / wellscope_figure6.py
- requirements.txt / .streamlit/config.toml

## 처음 사용하는 순서
1. 왼쪽 `작업 선택`에서 `표준 이미지 일괄 분석` 선택.
2. 실제 표준 사진을 여러 장 선택 → 혼합비 표 확인 → 확인란 선택.
3. `표준 이미지 분석 실행` 클릭. 기본 설정은 0% 대조 이미지의 신호 99백분위로 공통 well 임계값을 만듭니다.
4. 모든 시료의 격자와 비교 가능한 촬영·반응 조건 확인.
5. 기본 지표인 `공통 임계값 이상 well 비율 (%)`로 모델 검토. 모델이 만들어지지 않으면 분리가 안 된다는 뜻이며, 원하는 판정을 위해 임의로 결과를 바꾸지 않습니다.
6. 모델 저장/적용 확인란 선택 → `screening_model.json 저장`.
7. `단일 시료 분석` → `저장된 연구 선별 모델` → 모델과 사진 업로드 → `분석 실행` → 조건 확인.
8. 결과 저장은 `분석 결과 내보내기`에서 수행.

같은 이미지를 모델 개발에 사용했다면 결과에 `학습 이미지 재분석`이 표시됩니다. 미지 시료 예측에 파일명의 %를 읽어 넣는 기능은 없습니다. 세션이 종료되면 모델을 다시 업로드해야 하므로 JSON을 따로 보관하세요.

## 두 가지 기준을 구분
well 임계값은 형광 강도 단위, 시료 임계값은 선택한 요약 지표 단위입니다. 연구상 3%는 표준 시료의 GMO/non-GMO 혼합비 경계입니다. 이 셋을 같은 숫자로 취급하지 않습니다.

0–100% 정량이 보류되어도 이미지 계수/신호 분석과 연구용 선별 판정은 별도로 볼 수 있습니다. 다만 독립 시료로 성능을 검증해야 합니다. 정확도·민감도·특이도·불확도를 자동으로 만들어 표시하지 않습니다.

## 화면/기록
상단 카드의 글자색과 배경색을 함께 지정해 다크 테마의 대비 오류를 수정했습니다. 분석 방법 문장 영역은 삭제했습니다. CSV는 측정값, SVG는 그림 패널, HTML은 결과 보고서, ZIP은 이 파일들의 묶음입니다. 설정·QC는 JSON으로 남습니다.

A4 세로 Figure 6 SVG는 현재 데이터로 만든 개발 예시입니다. 실제 논문용 검증 그림은 독립 실험 자료로 D/E 패널을 교체하세요. 독립 반복 없이 오류 막대나 검증 성능을 만들지 마세요.

## 주의
v1.0 프로필은 v1.1에서 다시 만들어 주세요. 촬영 노출/gain, DNA 투입량, 희석, 반응 조건이 달라진 사진을 같은 모델에 무조건 적용하면 안 됩니다. 화면 확대는 원본 해상도를 늘리지 않습니다.

GitHub 웹 업로드는 .gitignore를 믿고 개인 사진을 함께 넣지 마세요. 프로그램 코드 ZIP만 공개 저장소에 올리고, 실험 결과/모델/원본 사진이 포함된 자료 ZIP은 개인 보관하세요.
